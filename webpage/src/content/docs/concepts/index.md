These pages explain how a BornEngine program is organized. Read them in order if you are new to game engines. Each page assumes the one before it.

1. [Game loop](./game-loop/) shows what runs every frame, in what order, and how a game stops.
2. [Scenes, objects, and components](./scenes-and-objects/) explains the three layers of a game and when each hook runs.
3. [API shape](./api-shape/) shows where names are imported from, and who owns each object.
4. [Assets](./assets/) covers file paths, loading, caching, and releasing resources.

If you want to build something right away, start with [Your first player](../getting-started/first-player/). It uses every idea on this page in a small program.
