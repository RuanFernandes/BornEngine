# Space Blaster

A small arcade shooter with a scrolling star field, pooled bullets and
explosions, three enemy types, successive waves, and a lives counter.

From this directory, install the local engine dependency and run the game:

```sh
npm install
bornengine run main.ts
```

Move with the arrow keys or **W/A/S/D** and hold **Space** to fire. Press
**Enter** after game over to restart.
