# Voxel Sandbox

A first-person 3D block sandbox demonstrating BornEngine's 3D camera, primitive
rendering, ray queries, and keyboard/mouse input.

From this directory, install the local engine dependency and run the game:

```sh
npm install
bornengine run main.ts
```

Move with **W/A/S/D**, use the mouse to look, and hold **Space** or **Left
Shift** to move vertically. Select a block with **1–7**; the left and right
mouse buttons place and remove blocks.
