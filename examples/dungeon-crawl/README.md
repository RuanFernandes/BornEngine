# Dungeon Crawl

A small turn-based dungeon game with procedurally placed rooms, corridors, a
line-of-sight reveal, pursuing enemies, stairs, and a follow camera.

From this directory, install the local engine dependency and run the game:

```sh
npm install
bornengine run main.ts
```

Move with the arrow keys or **W/A/S/D**. Press **.** to wait a turn and **+/-**
to change the camera zoom. After defeat, press **Enter** to start a new run.
