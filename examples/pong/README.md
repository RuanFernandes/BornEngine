# Pong

A two-player local Pong match built with a `Game` subclass. The paddles use the
keyboard, the ball bounces from the top and bottom edges, and rectangle
collisions determine each point.

From this directory, install the local engine dependency and run the game:

```sh
npm install
bornengine run main.ts
```

Player one moves with **W/S**. Player two moves with **Up/Down**. Press **P** to
pause or resume.
