# Isometric RPG

A compact isometric role-playing demo with a walkable village, NPC dialogue,
turn-based combat, collectible equipment, experience, and a camera that follows
the player.

From this directory, install the local engine dependency and run the game:

```sh
npm install
bornengine run main.ts
```

Move with the arrow keys or **W/A/S/D**. Press **Space** or **Enter** to advance
dialogue, and use **+/-** to zoom the camera.
